## 최단경로 (BOJ 1753)

> 🔗 [문제 링크](https://www.acmicpc.net/problem/1753)

## ⏱️ 문제 풀이 시간
**총 소요 시간: 약 60분**

---

## 📊 문제 난이도
🟡 **보통**

---

## ⚙️ 사용한 알고리즘
- **다익스트라(Dijkstra)**: 시작점에서 모든 정점까지의 최단 경로 탐색
- **우선순위 큐(PriorityQueue)**: 현재까지의 거리가 가장 짧은 노드를 우선 처리

---

## 💡 풀이 과정 (생각의 흐름)

### 1단계: 문제 분석

**핵심 파악**
> 방향 그래프에서 시작점 K로부터 모든 정점까지의 최단 경로를 구하는 문제. 간선 가중치는 양수(1~10)이므로 다익스트라 알고리즘 적용 가능.

**시간복잡도 검증**
```
정점 수: V ≤ 20,000
간선 수: E ≤ 300,000
PriorityQueue 사용 시: O((V + E) log V)
→ 약 300,000 × 15 ≈ 4,500,000 → 충분히 가능
```

---

### 2단계: 알고리즘 설계

**전체 흐름**

```
1. 인접 리스트 graph[V] 초기화
2. dist[] 배열을 INF로 초기화, 시작점은 0
3. PriorityQueue에 {0, start} 삽입
4. PQ가 빌 때까지:
   - 가장 짧은 거리의 노드 꺼내기
   - curDist > dist[curNode]이면 skip (이미 처리된 노드)
   - 이웃 노드 순회하며 더 짧은 경로 발견 시 dist 갱신 + PQ 삽입
5. dist[] 출력 (INF면 "INF", 아니면 숫자)
```

**그래프 자료구조**

```
graph → List<List<int[]>>  (크기 V)
graph.get(u) → [{v1, w1}, {v2, w2}, ...]  (u에서 갈 수 있는 간선들)
```

**PriorityQueue 정렬 기준**

```java
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
// {거리, 노드} 형태로 저장, 거리 기준 오름차순
```

---

### 3단계: 최종 구현

```java
import java.io.*;
import java.util.*;

public class Main {
    static BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
    static BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));
    static int INF = Integer.MAX_VALUE;
    static int V, E, K;

    public static void main(String[] args) throws IOException {
        StringTokenizer st = new StringTokenizer(br.readLine());
        V = Integer.parseInt(st.nextToken());
        E = Integer.parseInt(st.nextToken());

        st = new StringTokenizer(br.readLine());
        K = Integer.parseInt(st.nextToken());

        List<List<int[]>> graph = new ArrayList<>();
        for (int i = 0; i < V; i++) graph.add(new ArrayList<>());

        for (int i = 0; i < E; i++) {
            st = new StringTokenizer(br.readLine());
            int u = Integer.parseInt(st.nextToken());
            int v = Integer.parseInt(st.nextToken());
            int w = Integer.parseInt(st.nextToken());
            graph.get(u - 1).add(new int[]{v - 1, w});
        }

        int[] answers = dijkstra(K - 1, graph);

        for (int ans : answers) {
            if (ans == INF) bw.write("INF\n");
            else bw.write(ans + "\n");
        }

        bw.flush(); bw.close(); br.close();
    }

    private static int[] dijkstra(int start, List<List<int[]>> graph) {
        int[] dist = new int[V];
        Arrays.fill(dist, INF);
        dist[start] = 0;

        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        pq.offer(new int[]{0, start});

        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int curDist = cur[0], curNode = cur[1];

            if (curDist > dist[curNode]) continue;

            for (int[] next : graph.get(curNode)) {
                int nextNode = next[0];
                int nextDist = curDist + next[1];
                if (nextDist < dist[nextNode]) {
                    dist[nextNode] = nextDist;
                    pq.offer(new int[]{nextDist, nextNode});
                }
            }
        }

        return dist;
    }
}
```

## 📊 총 시간복잡도

```
O((V + E) log V) = O(320,000 × 15) ≈ O(4,800,000)
```

## 💁🏻 회고

**인접 리스트 초기화**
- `List<List<int[]>>`를 선언한 뒤 V개의 빈 리스트를 먼저 채워두는 것이 핵심
- 초기화 없이 `get(i)`를 호출하면 IndexOutOfBoundsException 발생

**PriorityQueue Comparator**
- `int[]`는 Comparable을 구현하지 않으므로 반드시 Comparator를 명시해야 함
- `(a, b) -> a[0] - b[0]` 으로 첫 번째 원소(거리) 기준 오름차순 정렬
