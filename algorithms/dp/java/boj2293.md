# 📝 문제 풀이 보고서
## 동전 1 (BOJ 2293)

> 🔗 [문제 링크](https://www.acmicpc.net/problem/2293)

---

## ⏱️ 문제 풀이 시간
**총 소요 시간: 약 30분**

---

## 📊 문제 난이도
🟡 **보통**

---

## ⚙️ 사용한 알고리즘
- **DP (동적 프로그래밍)**: 동전별로 dp 배열을 갱신하며 경우의 수 누적
- **1D DP (Unbounded Knapsack 유형)**: 동전을 중복 사용 가능한 조합 탐색

---

## 💡 풀이 과정 (생각의 흐름)

### 1단계: 문제 분석

**핵심 파악**
> n가지 동전으로 합이 k원이 되는 경우의 수를 구하되, **순서가 달라도 구성이 같으면 같은 경우**로 취급. 즉 조합의 수를 구해야 함.

**시간복잡도 검증**
```
동전 종류: n ≤ 100
목표 금액: k ≤ 10,000
→ O(n × k) = O(1,000,000) → DP로 충분히 가능
```

---

### 2단계: 알고리즘 설계

**DP 정의**
```
dp[j] = j원을 만드는 경우의 수
dp[0] = 1 (아무 동전도 쓰지 않는 1가지 방법)
```

**점화식**
```
for 동전 v:
    for i = v to k:
        dp[i] += dp[i - v]
```

**점화식 도출 이유**
- "i원을 만드는 방법" = "기존에 i원을 만들던 방법" + "동전 v를 한 장 더 썼을 때 i원이 되는 방법"
- 동전 v를 한 장 더 쓴다는 건, i - v원을 이미 만들 수 있으면 된다는 뜻이므로:
```
dp[i] += dp[i - v]
```


**순서 중복 방지 핵심**
- 바깥 루프를 **동전 종류**로 고정하면, 각 동전이 한 번씩만 고려되어 순서가 다른 중복을 자동으로 제거

---

### 3단계: 실수 및 수정 과정

| 단계 | 실수 | 수정 |
|----|------|------|
| 1차 | 안쪽 루프 조건 `(i - v) > 0` | `i == v`일 때 `dp[i] += dp[0]` 이 누락됨 → `>= 0` 으로 수정 |
| 2차 | dp 배열 크기를 `100_000`으로 과다 선언 | k + 1 = `10_001`로 수정 (메모리 제한 4MB 고려) |

---

### 4단계: 최종 구현

```java
public static int solution(int n, int k, int[] values) {
    int[] dp = new int[k + 1];
    dp[0] = 1; // 0원을 만드는 방법 = 아무것도 안 쓰는 1가지

    for (int v : values) {
        for (int i = 1; i <= k; i++) {
            if ((i - v) >= 0) dp[i] += dp[i - v];
        }
    }

    return dp[k];
}
```

---

## 📊 총 시간복잡도

```
O(n × k) = O(100 × 10,000) = O(1,000,000)
```

---

## 💁🏻 회고

**dp[0] = 1의 의미**
- 단순한 초기화 트릭이 아니라 "아무것도 선택하지 않는 1가지 방법"을 의미하며, 모든 경우의 수의 출발점이 됨
