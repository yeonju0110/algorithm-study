# 📝 문제 풀이 보고서
## 스티커 모으기(2) (프로그래머스 Level 3)

---

## ⏱️ 문제 풀이 시간
**총 소요 시간: 30분**

---

## 📊 문제 난이도
🟡 **보통**

---

## ⚙️ 사용한 알고리즘
- **DP (동적 프로그래밍)**: 각 위치에서 선택/비선택의 최적값을 누적
- **원형 배열 분리**: 첫 번째 포함 / 마지막 포함 두 가지 경우로 분리

---

## 💡 풀이 과정 (생각의 흐름)

### 1단계: 문제 분석

**핵심 제약 파악**
> 인접한 스티커는 선택 불가 → DP  
> 원형 배열 → 첫 번째와 마지막이 연결되어 있어 동시에 선택 불가

**원형 처리 방법**

첫 번째와 마지막을 동시에 선택할 수 없으므로, 두 가지 경우로 분리:
```
경우 1: sticker[0] ~ sticker[n-2] (첫 번째 포함, 마지막 제외)
경우 2: sticker[1] ~ sticker[n-1] (첫 번째 제외, 마지막 포함)
```
두 경우의 DP 결과 중 최댓값을 반환한다.

**왜 두 경우로 나누면 충분한가?**

sticker의 각 원소가 1 이상의 양수이므로, 첫 번째와 마지막 중 하나는 반드시 선택하는 것이 이득이다. 따라서 위 두 경우가 모든 최적해를 포함한다.

---

### 2단계: 점화식 설계

`dp[i]` = i번째까지 고려했을 때 가능한 최대합

```
dp[i] = Math.max(dp[i-1], dp[i-2] + sticker[i])
```

- `dp[i-1]`: i번째를 선택하지 않음 (i-1까지의 최대합)
- `dp[i-2] + sticker[i]`: i번째를 선택함

**주의**: `dp[i-1]`은 i-1을 선택했다는 의미가 아니라, i-1까지 고려한 최대합이다.
따라서 i와 i-1이 인접해도 안전하게 사용할 수 있다.

**점화식 손계산 예시** `[14, 6, 5, 11]`

| i | sticker | dp[i] | 선택 |
|---|---------|-------|------|
| 0 | 14 | 14 | 14 |
| 1 | 6 | 14 | 14 |
| 2 | 5 | 19 | 14, 5 |
| 3 | 11 | 25 | 14, 11 |

---

### 3단계: 초기값 설정

**경우 1** (첫 번째 무조건 선택):
```
dp[0] = sticker[0]
dp[1] = dp[0]  ← sticker[1]은 sticker[0]과 인접하므로 선택 불가
```

**경우 2** (첫 번째 선택 안 함):
```
dp2[0] = 0
dp2[1] = sticker[1]
```

---

### 4단계: 구현

```java
class Solution {
    public int solution(int sticker[]) {
        int n = sticker.length;

        if (n == 1) return sticker[0];

        int[] dp = new int[n];
        int[] dp2 = new int[n];

        // 경우 1: 첫 번째 포함, 마지막 제외
        dp[0] = sticker[0];
        dp[1] = dp[0];
        for (int i = 2; i < n - 1; i++) {
            dp[i] = Math.max(dp[i - 1], dp[i - 2] + sticker[i]);
        }

        // 경우 2: 첫 번째 제외, 마지막 포함
        dp2[0] = 0;
        dp2[1] = sticker[1];
        for (int i = 2; i < n; i++) {
            dp2[i] = Math.max(dp2[i - 1], dp2[i - 2] + sticker[i]);
        }

        return Math.max(dp[n - 2], dp2[n - 1]);
    }
}
```

## 📊 총 시간복잡도
```
O(N) - 배열을 두 번 순회
```

## 💁🏻 회고

- 원형 배열 문제는 **경우를 분리**해서 선형 DP로 변환하는 것이 핵심
- 점화식의 `dp[i-1]`이 "i-1을 선택"이 아니라 "i-1까지의 최대합"임을 이해하는 것이 중요
- 엣지 케이스 (`n=1`) 를 놓치지 않도록 주의
