## 💡 풀이 과정 (생각의 흐름)

### 1단계: 문제 분석 및 완전탐색 가능 여부 판단

**핵심 결정 사항 파악**
> (0, 0)에서 출발하여 (n-1, m-1)까지 **최소 칸 수**로 도달하는 경로 탐색

**이동 방식**
```
현재 위치 (x, y)에서:
→ (x-1, y) (북)
→ (x+1, y) (남)
→ (x, y-1) (서)
→ (x, y+1) (동)
```

**시간복잡도 검증**
```
맵 크기: n x m (최대 100 x 100 = 10,000)
각 칸에서 이동 방향: 4가지
→ O(n × m × 4) = O(40,000) → 완전탐색으로 충분히 가능
```

---

### 2단계: 알고리즘 설계

**BFS를 선택한 이유**

최단 경로(최소 이동 칸 수)를 보장하는 알고리즘 → BFS
```
상태: 캐릭터의 현재 위치 (x, y)
전이: (x, y) → 상하좌우 인접 칸
목표: (n-1, m-1)에 도달하는 최소 칸 수
```

**dist 배열 설계**

- `int[][]`로 선언하여 방문 여부와 거리를 동시에 관리
- 초기값 `INF`로 설정하여 방문 여부 명확히 구분
- BFS 특성상 **처음 방문한 순간이 항상 최단 거리**이므로, 이미 방문한 칸은 재방문 불필요

```
dist[0][0] = 1  (시작점, 출발 칸 포함)
dist[nx][ny] = dist[dx][dy] + 1  (다음 위치)
```

---

### 3단계: 구현

```java
import java.util.*;

class Solution {
    static int[] dr = new int[]{-1, 1, 0, 0};
    static int[] dc = new int[]{0, 0, -1, 1};
    static int INF = Integer.MAX_VALUE;

    public int solution(int[][] maps) {
        int n = maps.length;
        int m = maps[0].length;

        int[][] dist = new int[n][m];
        for (int i = 0; i < n; i++) Arrays.fill(dist[i], INF);

        Queue<int[]> queue = new LinkedList<>();
        queue.offer(new int[]{0, 0});
        dist[0][0] = 1;

        while (!queue.isEmpty()) {
            int[] curNode = queue.poll();
            int dx = curNode[0], dy = curNode[1];

            for (int i = 0; i < 4; i++) {
                int nx = dx + dr[i];
                int ny = dy + dc[i];

                if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;
                if (maps[nx][ny] == 0) continue;
                if (dist[nx][ny] != INF) continue; // 이미 방문한 칸 스킵

                dist[nx][ny] = dist[dx][dy] + 1;
                queue.offer(new int[]{nx, ny});
            }
        }

        return dist[n-1][m-1] == INF ? -1 : dist[n-1][m-1];
    }
}
```

## 📊 총 시간복잡도
```
O(n × m)  — 각 칸을 최대 1번만 방문
```

## 💁🏻 회고

**BFS가 최단 경로를 보장하는 이유**
- BFS는 가까운 노드부터 레벨 순서로 탐색하므로, (n-1, m-1)에 처음 도달하는 순간이 항상 최단 거리
- DFS는 최단 경로를 보장하지 않으므로 이 문제에 적합하지 않음

**방문 조건 설계의 중요성**
```java
// ❌ 틀린 조건: 같은 거리로 도달하는 경우도 큐에 재삽입됨
if (nextDist > dist[nx][ny]) continue;

// ✅ 올바른 조건: 이미 방문한 칸은 무조건 스킵
if (dist[nx][ny] != INF) continue;
```
- BFS에서는 처음 도달한 거리가 최단이므로, `>` 비교가 아닌 방문 여부만 체크해야 함
- 잘못된 조건을 쓰면 동일 거리로의 중복 방문이 발생하여 효율성 테스트 0점
