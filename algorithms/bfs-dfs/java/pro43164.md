## ⚙️ 사용한 알고리즘
- **DFS (깊이 우선 탐색)**: 모든 항공권을 사용하는 경로 완전 탐색
- **Hierholzer 알고리즘 (오일러 경로)**: 재귀 후 역순 삽입으로 경로 구성
- **PriorityQueue**: 알파벳 순 우선 방문 보장

---

## 💡 풀이 과정 (생각의 흐름)

### 1단계: 문제 분석

**핵심 결정 사항 파악**
> "ICN"에서 출발하여 **모든 항공권을 사용**하는 경로를 구성하되,
> 가능한 경로가 여러 개면 **알파벳 순서가 앞서는 경로**를 반환

**제약 조건 정리**
```
- 항상 ICN 출발
- 모든 항공권 사용 필수
- 경로가 여러 개면 알파벳 순 우선
- 모든 도시를 방문 불가능한 경우는 없음
```

---

### 2단계: 알고리즘 설계

**자료구조 선택**

| 자료구조 | 역할 |
|---|---|
| `HashMap<String, PriorityQueue<String>>` | 출발지 → 도착지 목록 매핑 |
| `PriorityQueue<String>` | 도착지를 알파벳 순으로 자동 정렬 |
| `LinkedList<String>` | 결과 경로 (앞에 삽입 가능) |

**DFS + 역순 삽입을 선택한 이유**

단순 반복문으로는 막힌 경로를 처리할 수 없어요.
DFS로 끝까지 탐색한 뒤, **되돌아오면서 앞에 삽입**하면 올바른 경로가 완성됩니다.

```
예) ICN → JFK → HND → IAD
IAD: 다음 없음 → result = [IAD]
HND: 다음 없음 → result = [HND, IAD]
JFK: 다음 없음 → result = [JFK, HND, IAD]
ICN: 다음 없음 → result = [ICN, JFK, HND, IAD] ✅
```

---

### 3단계: 구현

```java
import java.util.*;

class Solution {
    public String[] solution(String[][] tickets) {

        // 1. tickets 순회하며 HashMap + PriorityQueue 구성
        HashMap<String, PriorityQueue<String>> maps = new HashMap<>();
        for (String[] ticket : tickets) {
            String start = ticket[0];
            String end = ticket[1];

            maps.putIfAbsent(start, new PriorityQueue<>());
            maps.get(start).add(end);
        }

        // 2. DFS 탐색
        List<String> result = new ArrayList<>();
        dfs("ICN", maps, result);

        return result.toArray(new String[0]);
    }

    private void dfs(String airport, HashMap<String, PriorityQueue<String>> maps, List<String> result) {
        PriorityQueue<String> nextList = maps.get(airport);

        while (nextList != null && !nextList.isEmpty()) {
            String next = nextList.poll();
            dfs(next, maps, result); // 재귀
        }

        result.add(0, airport); // 앞에 삽입 (역순 구성)
    }
}
```

---

## 📊 총 시간복잡도
```
HashMap 구성: O(N log N)  - PriorityQueue 삽입
DFS 탐색:     O(N log N)  - 모든 티켓 1회 방문 × poll() 비용
→ 전체: O(N log N)
```

## 💁🏻 회고

**왜 역순 삽입(add(0, airport))인가?**
- DFS는 끝에 도달한 노드부터 반환됨
- 마지막 공항이 먼저 result에 들어가므로, 앞에 삽입해야 올바른 순서가 됨
- 뒤에 붙이고 마지막에 `Collections.reverse()`해도 동일한 결과

**단순 반복문이 안 되는 이유**
- 경로가 막히는 경우(dead end)를 처리할 수 없음
- DFS + 역순 삽입(Hierholzer 알고리즘)으로 해결

**PriorityQueue가 알파벳 순을 보장하는 이유**
- `PriorityQueue<String>`의 기본 정렬은 자연 순서(알파벳 오름차순)
- 별도 Comparator 없이도 알파벳 순으로 poll() 가능
