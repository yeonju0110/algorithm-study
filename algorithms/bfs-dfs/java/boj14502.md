## 연구소 (BOJ 14502)

> 🔗 [문제 링크](https://www.acmicpc.net/problem/14502)

## ⏱️ 문제 풀이 시간
**총 소요 시간: 약 70분**

## 📊 문제 난이도
🟡 **보통**

## ⚙️ 사용한 알고리즘
- **브루트포스 + 백트래킹**: 빈 칸 중 3개를 선택해 벽을 세우는 모든 조합 탐색
- **BFS (너비 우선 탐색)**: 바이러스 전파 시뮬레이션

---

## 💡 풀이 과정 (생각의 흐름)

### 1단계: 문제 분석 및 완전탐색 가능 여부 판단

**핵심 결정 사항 파악**
> N×M 격자에서 벽 3개를 세워 바이러스 전파 후 **안전 영역의 최댓값**을 구하기

**격자 구성**
```
0: 빈 칸
1: 벽
2: 바이러스
```

**시간복잡도 검증**
```
격자 크기: 최대 8×8 = 64칸
벽 3개 선택: C(64, 3) = 41,664가지
BFS 탐색: 최대 64칸
→ 41,664 × 64 = 2,666,496 → 브루트포스로 충분히 가능
```

---

### 2단계: 알고리즘 설계

**전체 흐름**

1. 빈 칸 목록(`emptySpaces`)과 바이러스 위치 목록(`viruses`) 미리 수집
2. DFS(백트래킹)으로 빈 칸 중 3개를 골라 벽 세우기
3. 벽 3개가 선택되면 BFS로 바이러스 전파 시뮬레이션
4. 남은 0의 개수를 세어 최댓값 갱신

**DFS 조합 선택 설계**

중복 선택을 막기 위해 `start` 파라미터로 이미 선택한 인덱스 이후부터만 탐색:

```
buildWalls(start=0, count=0)
  → i=0 선택 → buildWalls(start=1, count=1)
    → i=1 선택 → buildWalls(start=2, count=2)
      → i=2 선택 → BFS 시뮬레이션
      → i=2 해제
    → i=1 해제
  → i=0 해제
  ...
```

**백트래킹 적용**

처음에는 `List<int[]>`를 매번 복사하는 방식으로 구현했지만, 백트래킹으로 개선:

```java
// ❌ 매번 리스트 복사 (메모리 낭비)
List<int[]> nextArr = new ArrayList<>(arr);
nextArr.add(next);
dfs(i + 1, count + 1, nextArr);

// ✅ 백트래킹 (선택 후 되돌리기)
board[pos[0]][pos[1]] = 1;      // 벽 세우기
buildWalls(i + 1, count + 1);
board[pos[0]][pos[1]] = 0;      // 백트래킹: 빈 칸으로 복원
```

---

### 3단계: 구현

```java
static int N, M;
static int[][] board;
static List<int[]> viruses = new ArrayList<>();
static List<int[]> emptySpaces = new ArrayList<>();
static int maxSafeZone = 0;
static int[] dr = {-1, 1, 0, 0};
static int[] dc = {0, 0, -1, 1};

private static void buildWalls(int start, int count) {
    if (count == 3) {
        spreadVirus();
        return;
    }
    for (int i = start; i < emptySpaces.size(); i++) {
        int[] pos = emptySpaces.get(i);
        board[pos[0]][pos[1]] = 1;
        buildWalls(i + 1, count + 1);
        board[pos[0]][pos[1]] = 0;
    }
}

private static void spreadVirus() {
    int[][] newBoard = new int[N][M];
    for (int i = 0; i < N; i++) newBoard[i] = board[i].clone();

    Queue<int[]> queue = new LinkedList<>(viruses);
    while (!queue.isEmpty()) {
        int[] curr = queue.poll();
        for (int i = 0; i < 4; i++) {
            int nr = curr[0] + dr[i];
            int nc = curr[1] + dc[i];
            if (nr < 0 || nr >= N || nc < 0 || nc >= M) continue;
            if (newBoard[nr][nc] == 0) {
                newBoard[nr][nc] = 2;
                queue.add(new int[]{nr, nc});
            }
        }
    }

    int safeCnt = 0;
    for (int[] row : newBoard)
        for (int cell : row)
            if (cell == 0) safeCnt++;

    maxSafeZone = Math.max(maxSafeZone, safeCnt);
}
```

## 📊 총 시간복잡도

```
O(C(N×M, 3) × N×M) = O(41,664 × 64) ≈ O(2,700,000)
```

## 💁🏻 회고

**백트래킹의 핵심: 선택 후 반드시 되돌리기**
- 원본 `board`를 직접 수정하고, DFS 재귀 후 원래 값으로 복원
- 리스트 복사 방식 대비 메모리·속도 모두 개선

**BFS 시뮬레이션 시 원본 보호**
- 백트래킹으로 벽 정보는 `board`에서 관리
- 바이러스 전파는 `board.clone()`한 `newBoard`에서 수행하여 원본 훼손 방지
