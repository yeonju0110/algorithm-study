# 📝 문제 풀이 보고서
## 인구 이동 (BOJ 16234)

> 🔗 [문제 링크](https://www.acmicpc.net/problem/16234)

---

## ⏱️ 문제 풀이 시간
**총 소요 시간: 약 60분**

---

## 📊 문제 난이도
🟡 **보통**

---

## ⚙️ 사용한 알고리즘
- **BFS (너비 우선 탐색)**: 국경선 조건을 만족하는 인접 나라들을 묶어 연합 탐색
- **시뮬레이션**: 인구 이동이 없을 때까지 날짜별 반복 수행

---

## 💡 풀이 과정 (생각의 흐름)

### 1단계: 문제 분석

**핵심 파악**
> N×N 격자에서 인접한 두 나라의 인구 차이가 **L 이상 R 이하**이면 국경을 열고, 연결된 나라들의 인구를 균등 분배. 이를 변화가 없을 때까지 반복하여 **총 며칠이 걸리는지** 구하기

**시간복잡도 검증**
```
격자 크기: 최대 50×50 = 2,500칸
하루 시뮬레이션: BFS O(N²)
최대 반복 일수: 2,000일
→ 2,500 × 2,000 = 5,000,000 → 시뮬레이션으로 충분히 가능
```

---

### 2단계: 알고리즘 설계

**전체 흐름**

```
while (true) {
    visited 초기화
    모든 칸 순회하며 미방문 칸에서 BFS 시작
    BFS로 연합 탐색 → 인구 균등 분배
    인구 이동이 한 번도 없으면 → 종료
    이동이 있었으면 → days++
}
```

**BFS 연합 탐색 설계**

BFS 시작점에서 인접한 4방향을 탐색하며, 조건을 만족하는 칸만 연합에 포함:

```
조건: L ≤ |board[r][c] - board[nr][nc]| ≤ R
      && !visited[nr][nc]
```

연합 크기가 1이면 인구 이동 없음 → `return false`
연합 크기가 2 이상이면 인구 균등 분배 → `return true`

**초기 실수 및 수정 과정**

| 단계 | 실수 | 수정 |
|------|------|------|
| 1차 | BFS 시작점을 `areas`에 추가 안 함 | `union.add(start)` 추가 |
| 2차 | `visited`를 하루가 끝나도 초기화 안 함 | `while` 루프 시작마다 `visited = new boolean[N][N]` |

---

### 3단계: 최종 구현

```java
static int N, L, R;
static int[][] board;
static boolean[][] visited;

static final int[] DR = {-1, 1, 0, 0};
static final int[] DC = {0, 0, -1, 1};

public static int simulate() {
    int days = 0;
    while (true) {
        visited = new boolean[N][N];
        boolean moved = false;

        for (int i = 0; i < N; i++) {
            for (int j = 0; j < N; j++) {
                if (!visited[i][j] && bfs(i, j)) {
                    moved = true;
                }
            }
        }

        if (!moved) return days;
        days++;
    }
}

private static boolean bfs(int startRow, int startCol) {
    List<int[]> union = new ArrayList<>();
    Queue<int[]> queue = new ArrayDeque<>();

    visited[startRow][startCol] = true;
    queue.add(new int[]{startRow, startCol});
    union.add(new int[]{startRow, startCol});

    while (!queue.isEmpty()) {
        int[] cur = queue.poll();
        int r = cur[0], c = cur[1];

        for (int d = 0; d < 4; d++) {
            int nr = r + DR[d];
            int nc = c + DC[d];

            if (nr < 0 || nr >= N || nc < 0 || nc >= N) continue;
            if (visited[nr][nc]) continue;

            int diff = Math.abs(board[r][c] - board[nr][nc]);
            if (diff >= L && diff <= R) {
                visited[nr][nc] = true;
                queue.add(new int[]{nr, nc});
                union.add(new int[]{nr, nc});
            }
        }
    }

    if (union.size() == 1) return false;

    int total = 0;
    for (int[] cell : union) total += board[cell[0]][cell[1]];
    int avg = total / union.size();
    for (int[] cell : union) board[cell[0]][cell[1]] = avg;

    return true;
}
```

---

## 📊 총 시간복잡도

```
O(days × N²) = O(2,000 × 2,500) = O(5,000,000)
```

## 💁🏻 회고

**`moved` 플래그 관리**
- 처음에 static 전역 변수로 관리했으나, 지역 변수로 내리는 것이 더 안전하고 명확함
- BFS 반환값(`boolean`)으로 이동 여부를 표현하면 전역 상태 의존을 없앨 수 있음

**`LinkedList` → `ArrayDeque`**
- Queue 인터페이스 구현체로 `LinkedList`보다 `ArrayDeque`가 더 빠름
- BFS처럼 큐를 많이 사용하는 문제에서는 습관적으로 `ArrayDeque` 사용 권장
