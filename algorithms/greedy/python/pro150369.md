## 💡 풀이 과정 (생각의 흐름)

### 1단계: 문제 분석 및 접근법 고민

**문제의 핵심 통찰:**
- 트럭은 물류창고 ↔ 가장 먼 집까지 왕복해야 함
- **가장 먼 집부터 처리하는 것이 유리** (어차피 그 거리는 가야 함)
- 한 번의 왕복에서 배달 cap개, 수거 cap개를 **독립적으로** 처리 가능
- 배달과 수거는 서로 다른 집에서 이루어질 수 있음

**접근법 도출:**

**❌ 잘못된 접근: 배달과 수거를 따로 계산**
```
배달만의 왕복 + 수거만의 왕복
→ 비효율적 (동시에 처리 가능한데 따로 계산)
```

**✅ 올바른 접근: 그리디 + 역방향 누적**
```
1. 가장 먼 집부터 역순으로 순회
2. 배달/수거 물량을 누적
3. 누적량이 cap을 초과하면 왕복 필요
4. 왕복 거리는 현재 위치까지의 거리 × 2
```

**의사코드:**
```
총 거리 = 0
배달 누적 = 0
수거 누적 = 0

가장 먼 집부터 역순으로:
    현재 집의 배달/수거량을 누적에 추가
    
    누적량이 0보다 큰 동안:
        트럭 용량만큼 처리 (배달 누적 -= cap, 수거 누적 -= cap)
        현재 위치까지 왕복 거리 추가 (거리 × 2)
        
반환: 총 거리
```

## 💻 최종 코드

```python
def solution(cap, n, deliveries, pickups):
    total_distance = 0
    
    deliver_stack = 0  # 현재 배달해야 할 상자의 누적 개수
    pickup_stack = 0   # 현재 수거해야 할 상자의 누적 개수
    
    # 가장 먼 집부터 처리 (인덱스는 0부터 시작하므로 n-1부터)
    for i in range(n-1, -1, -1):
        # 현재 집의 배달/수거 상자 개수 누적
        deliver_stack += deliveries[i]
        pickup_stack += pickups[i]
        
        # 트럭 용량을 초과하는 경우, 왕복 횟수 계산
        while deliver_stack > 0 or pickup_stack > 0:
            # 한 번의 왕복으로 최대 cap개의 상자를 처리할 수 있음
            deliver_stack -= cap
            pickup_stack -= cap
            
            # 물류창고에서 현재 위치(i+1)까지 왕복 거리 추가
            total_distance += (i + 1) * 2
    
    return total_distance
```

### 📈 복잡도 분석

#### 시간 복잡도:
- **O(N + D/cap + P/cap)**
  - N: 집의 개수
  - D: 전체 배달 상자 개수의 합
  - P: 전체 수거 상자 개수의 합
  
**상세 분석:**
- 외부 for 루프: O(N) - 모든 집을 한 번씩 순회
- 내부 while 루프: 각 집에서 누적량을 cap씩 감소
  - 최악의 경우: 한 집에서만 모든 배달/수거가 발생
  - 총 반복 횟수: max(⌈D/cap⌉, ⌈P/cap⌉)
- **실질적으로 O(N)**에 가까움 (cap ≥ 1이고, 각 집의 물량 ≤ 50)

#### 공간 복잡도:
- **O(1)**
  - 입력 배열 외 추가 공간 사용 없음
  - 변수 4개만 사용 (total_distance, deliver_stack, pickup_stack, i)
  - 재귀 호출 없음

#### 실제 수치 (최악의 경우)
**입력:**
- n = 100,000
- cap = 1 (최소)
- deliveries = [50, 50, ..., 50] (모두 최대)
- pickups = [50, 50, ..., 50] (모두 최대)

**계산:**
- 전체 배달/수거량: 50 × 100,000 = 5,000,000개
- 각 집에서 while 루프: 50 / 1 = 50회
- 총 연산: 100,000 × 50 = 5,000,000회
- **여전히 충분히 빠름** (Python에서 초당 약 10^8 연산 가능)
