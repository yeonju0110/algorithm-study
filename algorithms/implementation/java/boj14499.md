# 📝 문제 풀이 보고서
## 주사위 굴리기 (BOJ 14499)

> 🔗 [문제 링크](https://www.acmicpc.net/problem/14499)

---

## ⏱️ 문제 풀이 시간
**총 소요 시간: 약 90분**

---

## 📊 문제 난이도
🟡 **보통**

---

## ⚙️ 사용한 알고리즘
- **시뮬레이션**: 명령에 따라 주사위를 굴리며 상태를 직접 추적
- **방향 벡터**: `dr[]`, `dc[]` 배열로 동/서/북/남 이동 처리

---

## 💡 풀이 과정 (생각의 흐름)

### 1단계: 문제 분석

**핵심 파악**
> N×M 지도 위에서 주사위를 명령에 따라 굴리며, 이동할 때마다 **윗면의 값**을 출력. 지도 칸과 주사위 바닥면 간의 값 복사 규칙을 정확히 구현해야 함.

**시간복잡도 검증**
```
명령 개수: 최대 K = 1,000
각 명령: O(1) 처리 (주사위 굴리기 + 보드 업데이트)
→ O(K) = O(1,000) → 시뮬레이션으로 충분히 가능
```

---

### 2단계: 알고리즘 설계

**전체 흐름**

```
for each cmd in commands:
    nx, ny = 다음 위치 계산
    if 범위 벗어남 → continue (출력 X)
    현재 위치 업데이트
    방향에 맞게 주사위 굴리기
    board[nx][ny] == 0 → 주사위 바닥면을 칸에 복사
    board[nx][ny] != 0 → 칸의 값을 주사위 바닥면으로 복사, 칸은 0으로
    윗면(dice[1]) 출력
```

**주사위 상태 관리**

전개도를 기준으로 인덱스를 정의:
```
      [2] 북
  [4] [1] [3]   →  dice[1]=윗면, dice[6]=바닥면
      [5] 남         dice[2]=북, dice[5]=남
      [6]            dice[3]=동, dice[4]=서
```

각 방향으로 굴릴 때 변하는 면만 업데이트 (나머지 면은 고정):

| 방향 | 변하는 면 |
|------|----------|
| 동쪽 | 윗면↔서쪽↔바닥↔동쪽 순환 |
| 서쪽 | 동쪽의 반대 순환 |
| 북쪽 | 윗면↔남쪽↔바닥↔북쪽 순환 |
| 남쪽 | 북쪽의 반대 순환 |

---

### 3단계: 실수 및 수정 과정

| 단계 | 실수 | 수정 |
|----|------|------|
| 1차 | `dr` 배열에서 북쪽 방향 부호 오류 | 북쪽은 r 감소이므로 `-1`로 수정 |
| 2차 | `roll` 함수에서 순차 대입으로 값 덮어씌움 | `dice.clone()`으로 복사 후 업데이트 |

---

### 4단계: 최종 구현

```java
// 동 -> 서 -> 북 -> 남
static int[] dr = { 0, 0, -1, 1 };
static int[] dc = { 1, -1, 0, 0 };

for (int cmd : cmds) {
    int nx = X + dr[cmd - 1];
    int ny = Y + dc[cmd - 1];

    if (nx < 0 || nx >= N || ny < 0 || ny >= M) continue;

    X = nx; Y = ny;
    int current = board[nx][ny];

    if (cmd == 1) dice = roll_east(dice);
    else if (cmd == 2) dice = roll_west(dice);
    else if (cmd == 3) dice = roll_north(dice);
    else if (cmd == 4) dice = roll_south(dice);

    if (current == 0) {
        board[nx][ny] = dice[6];
    } else {
        dice[6] = current;
        board[nx][ny] = 0;
    }

    bw.write(dice[1] + "\n");
}

private static int[] roll_east(int[] dice) {
    int[] newDice = dice.clone();
    newDice[1] = dice[4]; // 윗면 ← 서쪽
    newDice[3] = dice[1]; // 동쪽 ← 윗면
    newDice[6] = dice[3]; // 바닥 ← 동쪽
    newDice[4] = dice[6]; // 서쪽 ← 바닥
    return newDice;
}

private static int[] roll_west(int[] dice) {
    int[] newDice = dice.clone();
    newDice[1] = dice[3];
    newDice[3] = dice[6];
    newDice[6] = dice[4];
    newDice[4] = dice[1];
    return newDice;
}

private static int[] roll_north(int[] dice) {
    int[] newDice = dice.clone();
    newDice[2] = dice[1];
    newDice[1] = dice[5];
    newDice[5] = dice[6];
    newDice[6] = dice[2];
    return newDice;
}

private static int[] roll_south(int[] dice) {
    int[] newDice = dice.clone();
    newDice[2] = dice[6];
    newDice[1] = dice[2];
    newDice[5] = dice[1];
    newDice[6] = dice[5];
    return newDice;
}
```

## 💁🏻 회고

**주사위 면 인덱싱**
- 전개도를 보고 각 면의 인덱스를 명확히 정의하는 것이 핵심
- 처음부터 `dice[1]~dice[6]`에 의미를 부여하고 시작하면 실수를 줄일 수 있음
